# MoodFlix — Complete Local Project

Mood-based movie recommendation landing page — HTML, CSS, JavaScript only.

---

## ▶ How to run

**Double-click `index.html`** — opens in Chrome/Edge. Done.

Or in VS Code: right-click `index.html` → **Open with Live Server**.

No npm. No server. No install.

---

## 📁 Project folder (copy this whole folder to Desktop)

## ✅ What's included (fully complete)

- Responsive navbar with mobile menu
- Hero section with gradient title
- Features section with scroll animations
- **6 mood cards** (Happy, Sad, Thriller, Romantic, Chill, Adventurous)
- **Movie recommendations** on mood click
- **Save mood** to localStorage with toast notification
- How it works (3 steps) with scroll reveal
- CTA button scrolls to mood picker
- Footer with GitHub link
